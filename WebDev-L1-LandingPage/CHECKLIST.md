# Oasis Level 1 Landing Page Checklist

- [x] HTML5 and CSS3
- [x] Sticky navigation with at least three links
- [x] Hero headline, subheadline and CTA
- [x] At least two distinct content sections
- [x] Footer with contact and social placeholders
- [x] Consistent color palette and typography
- [x] Responsive desktop, tablet and mobile CSS
- [x] Local visual assets; no broken remote image dependencies
- [x] Descriptive image alt text
- [x] Keyboard focus-visible states
- [x] Reduced-motion support
- [ ] Manually inspect at 1440, 1024, 768, 390 and 320px in Chrome
