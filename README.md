AHA — Premium Skincare Landing Page
A fictional premium skincare brand website created for Oasis Infobyte Web Development Level 1, Task 1.

Run
Extract the ZIP, open this folder in VS Code, then open index.html in a browser or use Live Server. No backend, database, package installation, or build step is required.

Technology
HTML5, CSS3, local image assets, and optional Google Fonts with fallback fonts.

Included
Luxury editorial hero, skincare product collection, philosophy, ritual, brand values, campaign, newsletter demo, contact and footer.

Image note
This edition includes locally stored AI-generated skincare concept imagery. These are not actual commercial product photographs or Pinterest downloads. AHA and all product names/details are fictional sample content. The newsletter is frontend-only and does not send or store submissions.
