## How to Run

Follow these steps to run the AHA Landing Page locally.

### 1. Clone the Repository

```bash
git clone https://github.com/JAFSHI3072020-lgtm/OIBSIP.git
```

### 2. Open the Project Folder

```bash
cd OIBSIP/WebDev-L1-LandingPage
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the Website

**Option 1: Using VS Code Live Server**
1. Install the Live Server extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.

**Option 2: Without Live Server**
1. Open the project folder.
2. Double-click `index.html`.
3. The website will open in your default browser.

### Requirements
- Visual Studio Code (recommended)
- A modern web browser
- Live Server extension (optional)

**Note:** This is a frontend-only project built with HTML5 and CSS3. No backend installation is required.
